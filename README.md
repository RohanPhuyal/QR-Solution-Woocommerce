# QR Solution WooCommerce

A powerful, lightweight WooCommerce extension that enables **QR Code Payments** (digital wallets, bank transfers) with proof-of-payment uploads. Perfect for markets using Yape, Plin, or direct bank transfers.

## 🚀 Features

*   **Unlimited QR Options**: Add multiple payment methods (e.g., Bank #1, Wallet #2) with custom icons and QR codes.
*   **Payment Receipt Upload**: Customers can upload a screenshot of their transaction directly at checkout.
*   **COD Mode**: specialized "Cash on Delivery" toggle.
    *   **Pre-payment Logic**: Require shipping costs to be paid upfront via QR while the rest is COD.
*   **Dynamic Popups**: Smart payment popups that automatically show the correct amount (Total vs. Shipping Only).
*   **Order History**: Receipts are saved to the order and viewable in the Admin panel.
*   **Seamless Integration**: Works with standard WooCommerce checkout.

## 📦 Installation

1.  Download the repository zip.
2.  Go to **WordPress Admin > Plugins > Add New > Upload Plugin**.
3.  Upload and Activate.
4.  Navigate to **WooCommerce > Settings > Payments > QR Payment Solution**.
5.  Configure your QR codes and options.

## 🔧 Configuration

*   **Enable/Disable**: Turn the gateway on or off.
*   **Title/Description**: Customize what the customer sees.
*   **QR Options**: Use the "Add Option" button to create multiple payment destinations.
*   **COD Mode**: Enable to show a toggle between "Full Payment" and "Cash on Delivery".
